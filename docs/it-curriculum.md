# 软件开发商务日语课程说明

这套课程面向 Java / Spring Boot 后端开发岗位，兼顾前端协作。训练目标是直接用日语说明任务、代码、调查结果、风险和协作请求，能继续回答追问，并写出工作消息与客户联络。

课程共有 23 章、82 课。保留原有 40 课职场路线与 6 课后端基础，新增 12 章、36 课专项场景；同时增强全部原有课次。当前有 1,204 条场景词汇、210 段对话、1,476 句、246 组固定表达、246 道作业。相同词在不同工作场景中的条目分别保留，词汇条目数不等于去重词数。

## 每课怎样练

全部课次包含主对话和现场追问。追问按本课情境编写，例如“增加索引会影响登记吗”“旧版能读取新版数据吗”“按钮禁用能完全防止重复提交吗”。原有课次保留原主线与素材，再增加追问、两个固定表达及三类练习。

新增 36 课每课包含 12 句主对话、6 句追问、4 句对外语体，共 22 句；12～26 条词汇及搭配与日中例句；三组固定表达；工作消息、确认清单和正式邮件示范；跟读任务；三类作业与参考答案。

三类作业分别练习：用 30～60 秒口头说明事实、原因或未确认项、方案和请求；写出对象明确、请求具体的工作消息；听到条件变化后即时回应。参考答案是表达示范，涉及期限、技术策略和业务条件时，应结合题目与自己项目进行替换。

词汇、例句、对话和参考答案提供播放入口。英文技术名称以明确的日语读法进入朗读文本，正文仍保留实际代码和接口名称。正式邮件先练主题、事实、行动、请求与后续联络；对外使用时还要把技术原因转换为客户能理解的业务影响。

## 建议学习顺序

1. 从 onboarding、setup、workflow 建立“确认—汇报—请求”的基础，再学 requirements 到 operations 的开发全过程。
2. Java 岗位先学 java-backend，再按 java-core → spring-development → api-development → data-access → transactions → backend-testing 深入常用讨论。
3. 学 cache-messaging、delivery-runtime、application-security，练习运行问题、部署与协作边界。
4. 学 frontend-collaboration 和 business-systems，把后端接口与画面及实际业务联系起来。
5. business-communication 可贯穿全程。最后用 handover、ownership 练习接手系统与独立推动任务。

网站 `/vocabulary/` 默认展示全部词汇。可用日语、读音、中文或例句搜索，再按章节筛选；点击条目对应课文，回到上下文练习。无需逐条死记全部词：先按当前工作任务选场景，再在词汇页补相关说法。

## 怎样判断能否在上班时用出来

完成一课后，隐藏中文和原文，先独立口述，再打开示范比较。检查自己能否说清对象、事实、未知条件、方案、影响、请求；能否回答本课的现场追问；能否写出带具体请求的短消息。把订单换成工单、把本地环境换成生产环境后再说一次，避免仅记住一句课文。

词汇覆盖和表达能力要分别判断。当前内容已覆盖通用开发岗位的主要工作场景；公司的专有业务、内部缩写、特定框架版本与团队习惯仍需在实际项目里补充。N3 是进入课程的学习起点，不表示所有技术词或商务表达都属于 JLPT N3，也不表示完成浏览就具备即兴沟通能力。

# 审计商务日语课程说明

课程入口：`/courses/audit-business/`。完整参照相邻参考仓 `aduit-nihongo/data/course` 的 12 章、86 个主线学习日和 20 个补充专题，在当前平台组织为 **106 节可独立学习的课件**。没有把原来的 86 个学习日误算成 106 个主线学习日；专题按原推荐学习日穿插在对应主课后。

这条路线面向会计审计现场的商务沟通：索取和追踪资料、澄清业务事实、说明差异与金额方向、保留未确认状态、提出后续程序、内部汇报、撰写底稿及结项。重点是把同一个事实分别说给客户、内部负责人，并写进可追溯的记录。原来的 1/2/3 是任务难度阶段，课程不标为 JLPT N1/N2/N3。

## 原九阶段如何进入当前平台

| 参考仓训练阶段 | 当前平台位置                                               |

| 场景           | 目标、现场信息、主课文与分支选择器                         |

| 主动词汇       | 词汇区、主动词汇原例句素材                                 |
| 审计识读       | 词汇区、识读说明表                                         |
| 搭配           | 句型区、搭配模板素材                                       |
| 文法           | 独立文法区，含接续、中文说明与原例句                       |
| 听力           | 听读区“播放听力”，原文默认折叠；作业区包含原问题与参考答案 |
| 跟读           | 对话跟读控制、功能句版本与功能提示表                       |
| 练习           | 客户口头输出、内部书面输出与口头复述、底稿表达及原自评标准 |

推荐每节按“目标 → 主课文 → 分支追问 → 词汇／识读 → 三种语体与文法 → 盲听 → 跟读 → 输出作业”学习。盲听前不要展开原文；听后先回答作业中的问题，再看原文和证据。输出时始终区分已经确认、尚未确认和计划执行的事项，把对象、期间、金额方向、证据和下一步说完整。

对话中的学习者固定为“我（わたし）”，原客户、前辈和组成部分团队继续作为对话对象。集团审计专题中，学习者承担集团团队角色；跟读功能标签保留在素材表中，功能句仍由学习者说出。设备语音和 VOICEVOX 使用平台现有语音设置，课程未增加新的运行依赖。

## 来源与保留范围

参照数据为参考仓的 `catalog.json`、`chapters/01.json` 至 `12.json`、`supplements.json` 和 `references.json`。原目录、题目、现场信息、任务、主对话、分支、三种语体、词汇、识读说明、搭配、文法例句、听力问题／答案／证据、跟读功能、双输出示范、条件、金额和自评标准均保留。原文来源写入每课 references。

`tests/fixtures/audit-import.json` 保存 16 个来源文件的 SHA-256 与 106 节课的原始学习文本片段摘要。完整性测试逐课检查这些片段仍在转换后的课件中，CI 无需读取相邻参考仓。当前课程是独立快照，日后参考仓更新不会自动同步。

原主对话、分支、语体和专题示范保留日中对照。原本只有日文的主动词汇原例句、文法例句、主线输出示范和听力证据保持原样；主动词汇素材附“词义提示”，文法附“用法说明”，这些说明不冒充整句译文。词汇卡片另选用原双语句或补充译文提供日中例句。朗读字段补全假名，金额、编号和专业术语做读音处理，不修改原日文案例。

原课程的会计、税务和审计判断按各题给定假设保留，标准来源链接继续附在课件中。租赁专题等含有具体适用日期的内容保留原来源与条件，不将题目案例扩写成适用于所有企业的判断。
